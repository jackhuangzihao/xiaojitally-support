# 记账修复验收 · 0.2.4（40）

> 整理说明（2026-10-05）：本文保留原有说明。文中构建、源码、备份等相对路径以桌面“软件/简事”工程根目录为起点；当前版本与运行方式以根目录 README.md 为准。

日期：2026-09-29。仅调整记账逻辑和相关界面；没有修改数据结构或备份格式。

## 修复

1. 历史余额核对按选择的日期时间计算基准，不再把之后的流水算进差额；保存前重新核对基准，防止编辑期间余额变化。
2. 修改外币转账手续费时，尚未手动覆盖的折算手续费跟随原记录汇率更新；保留手动输入。
3. 复制跨币种转账同时检查转出和转入账户币种，清空旧到账金额及相关折算值；归档账户不再被带入新记录。
4. 新交易不允许使用归档账户，账本的归档默认账户不再自动带入；历史编辑、原账单退款和主动余额核对仍可处理归档账户。
5. 全部账本的预算包含归档账本；预算进度只统计设有预算账本的支出、手续费和退款。无预算账本的收支仍计入总览，界面解释其不占用其他账本预算。
6. 搜索包含转入账户名称，同时保留标题、备注、标签、转出账户和分类等字段。

## 体验

- 账单页可组合账本和账户筛选，结果取交集；资产账户详情仍汇总所有账本，筛选状态与详情状态分开。
- 账户详情的“筛选”菜单新增“显示逐笔余额”，默认关闭。余额按完整账户历史计算；同一时刻按界面稳定顺序累计，隐藏金额时一并隐藏。
- 日、周、月、年范围的日期标题可点击，复用已有日期选择器快速跳转年月。
