- 移除鼠标移动时持续计算任务矩形并刷新整个周历的逻辑；缓存日期和金额格式化器，减少重复创建；时间指示按分钟刷新。

## 财务示例怎么用

打开 **财务 → 记账管理 → 数据与设置 → 添加示例账本**。

准备了 2 个账户、3 笔账单、1 个子分类：

| 示例 | 内容 |
| --- | --- |
| 人民币卡 | 招商银行，期初 ¥1,000，午餐支出 ¥38，余额 ¥962 |
| 美元卡 | HSBC，期初 US$100，咖啡支出 US$8，收入 US$120，余额 US$212 |
| 默认账户 | 示例账本默认美元卡，账单合计自动显示 USD |
| 分类 | 示例餐饮 → 咖啡 |

示例名称有明确标记，可通过“清除示例数据…”移除，清理前保存完整备份。示例加入后会计入资产总额，不改写现有账户余额、默认账户或汇率。没有自动把示例写入用户真实账本。

没有汇率时会显示“待补充汇率 / 待换算”，可用来检查缺失汇率的显示；示例不会虚构市场汇率。资产参考汇率可自动更新或手动填写，历史账单折算另行保留。
