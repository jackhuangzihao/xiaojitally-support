# iCloud 同步准备与接入记录

> 整理说明（2026-10-05）：本文保留原有说明。文中构建、源码、备份等相对路径以桌面“软件/简事”工程根目录为起点；当前版本与运行方式以根目录 README.md 为准。

## 当前状态 · 0.1.17（build 19）

本次是同步前的数据适配，尚未连接 iCloud。正式运行的 Mac 应用暂保留 0.1.16；本文件夹源码已准备为 0.1.17。所有数据库仍显式使用 `cloudKitDatabase: .none`，不会上传真实任务，也不会仅因为开通会员就自动上传。

### 已完成

- 将 `TaskList.tasks` 改为可选关联，保留属性名称和反向关联，符合 CloudKit 对关联允许为空的要求。没有改变任务编号、清单编号或 JSON 备份格式。
- 本地检查所有持久属性均可空或有默认值、没有唯一约束，所有关联可空且不采用 deny 删除规则。此检查不是 CloudKit 服务端模式验证。
- 默认数据库在首次打开新结构前，使用 SQLite 原生备份接口保存一致性副本，包含已经提交的 WAL 日志数据；校验后才原子落盘。副本只创建一次，不被日常保存覆盖；无法创建时停止打开数据库，不以空库替代。
- 副本位于原数据库旁的 `SchemaBackups/<数据库名>.before-cloud-schema-v1.sqlite`。这是升级救援文件，需要技术协助恢复；日常换设备仍使用设置中的 JSON 导出、恢复。
- 设置增加“数据与同步 / 仅保存在本机”，明确本版尚无自动同步。保留离线保存、自动多版本备份及写入失败后的重新载入。
- 不添加无效的同步开关或虚假的“已同步”时间。

### 验证结果

- Mac 通用 Release 编译通过，472 项常规自检通过。
- 使用修改前 0.1.16 的模型生成真实 SQLite 样本，再用新结构打开，与旧版事先导出的完整 JSON 内容逐项比较。包含嵌套清单、颜色、emoji、起止时间、截止、提醒、重复及下一次任务链接、完成状态、最近删除、无日期任务、备注和子任务。带迁移验证共 475 项通过。
- iPhone 模拟器编译和 418 项适用自检通过；iPhone 真机 Release 未签名编译通过。
- 新增检查覆盖：可选关联、原数据库连接尚未关闭时的保护副本、旧副本不会被新修改覆盖、删除清单保留任务、源文件缺失不创建空库、损坏源文件不改变原文件、不残留未完成副本。
- 没有实际云端同步测试、真机同步测试或并发冲突验证；不声称本版本已具备这些能力。

## 会员开通后的接入顺序

1. 确认开发者团队、应用标识和 CloudKit 容器标识，在两端使用同一个容器；配置 iCloud、CloudKit 和相应后台通知权限。先在开发环境使用隔离样本，不对生产数据直接试错。
2. 先备份 Mac、iPhone 各自的数据。首次合并必须保留两端内容，区分同一编号和不同编号，不能把整库导入覆盖当成双向同步；同一编号不同内容需要明确处理方案。
3. 在真实 CloudKit 配置下验证模型，包括 Codable 子任务存储。通过后再接入系统同步事件；本地保存成功不能当作上传完成。
4. 状态文案区分：仅本机、正在同步、等待联网、空间不足、账户不可用及同步错误。任何云端失败不应触发本机数据库的写入故障保护，也不能阻止离线编辑。
5. 同步新数据后刷新本地提醒和备份；云端删除、恢复、移动清单、关联暂时缺失时的界面必须一致。自动默认清单、唯一颜色及两端同时完成重复任务需专门处理，防止重复创建或互相反复修改。
6. 账号退出或切换时停止原账号同步，不把原账号本地数据自动上传给新账号。先实现并验证明确的账户隔离与确认流程。
7. 双机验证首次合并、双端离线后重连、同项同时编辑、一端删除另一端修改、重复任务去重、空间不足后恢复、保存失败恢复、备份追加/替换与云端数据的交互。
8. 通过后才部署生产 schema，制作 TestFlight 构建，再小范围验证升级及卸载重装。保持多版本备份，不能用同步代替备份。

## 本地复核

运行编译产物的可执行文件并传入 `--self-check`，自检仅使用临时数据库。可设置 `JIANSHI_MIGRATION_COPY` 指向旧版数据库的副本，设置 `JIANSHI_MIGRATION_EXPECTED` 指向该旧版提前导出的 JSON，以进行完整内容核对。不要让这两个变量指向正在使用的真实数据库。

本次旧版样本是在独立旧版工程中生成；修改前源码保存在本工程的历史归档目录，可重建旧模型样本。原先的 1–5 版 JSON 备份仍受支持。

参考：[SwiftData 跨设备同步](https://developer.apple.com/documentation/swiftdata/syncing-model-data-across-a-persons-devices)、[启用 CloudKit](https://developer.apple.com/documentation/cloudkit/enabling-cloudkit-in-your-app)。
